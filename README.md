 Retail Sales Analysis Using Excel

 Project Overview

This project focuses on analyzing retail sales data using Microsoft Excel. The main objective is to understand sales performance, identify top-performing products, analyze regional sales and gain useful business insights from the dataset.

 Business Objectives

- Analyze overall sales performance.
- Identify the best-performing products.
- Compare sales across different regions.
- Understand customer purchasing patterns.
- Analyze profit and revenue.
- Explore different payment methods.
- Identify sales trends and patterns.

 Dataset Information

- Dataset: Retail Sales Dataset
- Total Records: 1,500
- Total Columns: 19
- File Format: Excel (.xlsx)

Key Columns

- Date
- Region
- Product
- Quantity
- Unit Price
- Store Location
- Customer Type
- Discount
- Salesperson
- Total Price
- Payment Method
- Returned
- Order ID
- Customer Name
- Shipping Cost
- Order Date
- Delivery Date
- Region Manager
- Profit

 Tools Used

- Microsoft Excel
- Pivot Tables
- Data Analysis
- Charts and Visualizations

 Project Analysis

The project explores the following areas:

1. Product-wise Sales Analysis
2. Region-wise Sales Analysis
3. Customer Type Analysis
4. Profit Analysis
5. Payment Method Analysis
6. Salesperson Performance
7. Quantity Sold Analysis
8. Return Analysis

 Key Insights

- Total sales across the dataset are approximately 4.38 million.
- Tablets generated the highest total sales among the listed products.
- Phones recorded the lowest total sales among the listed products.
- Product-wise sales analysis helps identify high-performing and low-performing products.

 Project Files

- "EXCEL_PROJECT.xlsx" – Original dataset and Excel analysis.

 Conclusion

This project demonstrates how Microsoft Excel can be used to analyze retail sales data and generate meaningful business insights. The analysis helps understand product performance, sales trends and profitability, supporting better business decision-making.
